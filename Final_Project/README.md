# Project Final
This project consists of three main components: data preprocessing, baseline sequence modeling, and an XGBoost-based automatic labeling model. The purpose of this repository is to organize all relevant datasets, notebooks, and reports used throughout the project. The roles of each file and folder are described below.

## Dataset folder
This folder contains all raw BAS data files (one file per data point) as well as the integrated dataset used for modeling:
Building_AllPoints_15m_2025Jan01_2025Oct01_COV_and_15min.csv.
It also includes AutoTag_XGBoost_Results.csv, which is the prediction output generated by the XGBoost tagging model.

## CSCP.ipynb
This notebook performs data preprocessing. It loads the raw files, aligns timestamps, cleans and normalizes values, and generates the final integrated dataset used across the project.

## Baseline_LSTM.ipynb
This notebook implements a baseline LSTM sequence model using the integrated dataset. It trains and evaluates the model to establish baseline performance for comparison against other approaches.

## XGBoostMapping.ipynb
This notebook implements an XGBoost-based automatic labeling (auto-tagging) model. It predicts the semantic type of each data point based on patterns in the values. The prediction results are saved to AutoTag_XGBoost_Results.csv inside the Dataset folder.

## P23_Project Final Report.pdf
This is the final report summarizing the project objectives, preprocessing pipeline, model designs, experimental results, and key findings
